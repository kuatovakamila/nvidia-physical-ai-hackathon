# Kitchen Assistant — раннбук запуска

Команды взяты дословно из пакета хакатона. Всё, что помечено «после доступа»,
требует signup-ссылки на Antioch Console (раздают после формирования команд).

## 0. До ивента (можно сегодня)

1. **Каждый:** поставить `uv` (docs.astral.sh/uv) или miniconda.
2. **P5 + один дублёр:** окружение для обучения (Guide 1, шаг 1 — железо не нужно):
   ```bash
   conda create -n lerobot python=3.10 ffmpeg -c conda-forge -y
   conda activate lerobot
   pip install lerobot opencv-python
   python -c "import torch; print('MPS:', torch.backends.mps.is_available())"
   ```
   Должно напечатать `MPS: True`. Никакого CUDA на Mac — его не существует.
3. **P2:** прогнать и прочитать `planner.py` и `monitor.py`:
   ```bash
   python3 planner.py && python3 monitor.py
   ```
   Оба самотеста зелёные. Поиграть со сценой в `__main__` — добавить второй
   блокер, подвигать объекты, убедиться, что поведение понятно.
4. **Все:** прочитать Guide 2 целиком (наша сантехника) и «Engine gotchas» из Guide 4.

## 1. T+0 — как только есть доступ (P1, ~10 минут)

```bash
cd ~/my-sim && uv sync
.venv/bin/antioch auth login

# Прогреть машину — холодная виснет на первом рендере (~25 c):
.venv/bin/antioch scenario run --scenario so101_render_probe

# Стоковый эксперт end-to-end — доказать, что сантехника жива:
.venv/bin/antioch scenario list --limit 5
.venv/bin/antioch scenario download <run-id>   # один эпизод: .mp4 + .npz на месте
```

Железное правило пакета: только `~/my-sim/.venv/bin/antioch` и только из
`~/my-sim`. Голый `antioch` в PATH — другой бинарь.

**P5 стартует параллельно, не дожидаясь никого:** генерация эпизодов
(Guide 3, шаг 1) → данные к 11:00 → `lerobot-train --policy.type=act
--steps 15000 --batch_size 8` запущен к 11:30, доучивается за обедом.

## 2. Разведка 10:30–10:50 (P1 + P2)

1. Найти функцию **поза → waypoints** у эксперта:
   ```bash
   grep -rn "waypoint\|grasp\|expert" ~/my-sim/src/ | head -30
   ```
   Это точка встраивания `_execute()` из `kitchen_suite.py`.
2. Ассеты: есть ли в библиотеке Antioch **vial / контейнер / кружка /
   столешница**? (Док-страница ассетов + пробный `load_asset`.)
   Тайм-бокс на «кухонную» одёжку — 15 минут, иначе цветные кубы с подписями.
3. Как читается ground-truth поза объекта в сценарии (для `_true_xy` /
   `_state_for`) — подсмотреть в скоринг-коде самого suite.

## 3. Гейт 11:15 — выбор оболочки

| Если к 11:15… | Решение |
|---|---|
| Vial берётся перенацеленным экспертом | Полный Kitchen Assistant |
| Vial есть, но захват капризный | Кубы как «объекты», vial только в финальном демо |
| Vial-ассета нет | Кубы с подписями; вся логика без изменений |

Гейт по плану, не по прогрессу: скелет (эпизодный retry без mid-phase
детекции) должен работать **до обеда**.

## 4. Роли

| Кто | Владеет | Первая задача |
|---|---|---|
| P1 | машина, сессии, глюэ-код suite | T+0 блок, потом `_execute()` + TODO в `kitchen_suite.py` |
| P2 | `planner.py`, `monitor.py`, пороги | подкрутить пороги под реальный vial, тест «спавн в стороне» |
| P3 | eval-батчи, парсинг логов, график | два запуска suite, число X% vs Y% на слайд |
| P4 | демо: стрим, perception, саботаж, бэкап-видео | HSV-классификация цвета с кисти; видео одного recovery — рано |
| P5 | policy-трек (Guide 3) | данные 11:00 → train 11:30 → жёсткий гейт 14:30 |

## 5. Грабли из пакета (проверено чужой кровью)

1. Код сценария фиксируется на момент запуска сессии — правки «вживую» не
   применяются. Итерации только через новый headless-запуск.
2. Никакого `pkill` внутри контейнера — вешает exec-канал. Ждать
   `max_seconds` или `antioch machine reset` + прогрев заново.
3. Пайп только через `machine exec`, не `machine ssh` (у ssh другой fs).
4. Видео с замёрзшим роботом при живой физике → флаги Fabric из Guide 4
   (`--/app/useFabricSceneDelegate=0` и компания).
5. Первый кадр камеры чёрный → warm-render до первого решения; near clip
   выставить явно (0.05 м).
6. Если P5 трогает датасеты: в `action` — **commanded targets**, не
   measured positions, иначе политика замирает под нагрузкой.
7. Заморозка кода в 14:45. После — только видео, прогон питча, сабмит к 15:30.

## 6. Питч (каждому судье, 30 секунд)

робот сам уберёт мешающий стакан, поднесёт лекарство в зону досягаемости и
проверит, что оно стоит. Мы намеренно смещаем захват: без супервизора X%
успеха, с ним Y%. Поставьте препятствие куда хотите — он разрулит.»
